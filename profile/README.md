# Cornerstone — Professional SVN Client for Legacy Enterprise Projects

## About Cornerstone

Cornerstone provides a professional Subversion (SVN) client for legacy enterprise projects, older codebases, and teams still using centralized version control. Cornerstone combines repository browsing, timeline view, and working copy management. Cornerstone supports conflict resolution, annotation, and export tools. Cornerstone integrates with Subversion servers (HTTP, HTTPS, SVN+SSH, file protocol). Cornerstone enables teams to maintain legacy applications, transition to Git gradually, and support older build systems. Cornerstone is trusted by enterprise IT departments, game studios with legacy assets, government contractors, and financial institutions worldwide.

## Deep Dive — SVN Client Features
Repository browsing with folder tree and file revision history
Timeline view showing commits over time with author coloring
Working copy management for multiple checked-out locations
Conflict resolution with three-way merge editor
Blame/annotation showing last change per line with revision number

## Quick Reference for Cornerstone

| Operation | Cornerstone Action |
|-----------|---------------------|
| Repository browse | Cmd+R |
| Timeline view | Cmd+T |
| Working copy status | Cmd+W |
| Commit changes | Cmd+Shift+C |
| Update | Cmd+Shift+U |
| Resolve conflict | Cmd+Shift+R |
| Blame annotation | Cmd+Shift+B |
| Export working copy | Cmd+Shift+E |
| Diff comparison | Cmd+D |
| Show log | Cmd+L |
